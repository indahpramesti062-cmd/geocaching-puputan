Telusuri 7 situs bersejarah Perang Kusamba & Puputan Klungkung di Kota Semarapura, Bali

📖 Tentang Game

Game ini mengajak kamu menelusuri jejak perjuangan Kerajaan Klungkung melawan kolonialisme Belanda (1849–1908). Kunjungi lokasi-lokasi bersejarah, pecahkan teka-teki, dan pelajari sejarah melalui narasi interaktif.

🗺️ Cara Bermain

1. Jawab clue/teka-teki untuk menemukan koordinat cache
2. Gunakan GPS untuk navigasi ke lokasi
3. Konfirmasi posisi saat jarak ≤30 meter
4. Baca materi sejarah & jawab post-test
5. Lanjut ke level berikutnya!

⚠️ Persiapan

Pastikan GPS/lokasi aktif. Game ini membutuhkan kunjungan langsung ke lokasi di area Klungkung, Bali. Level 0 (Prolog) bisa dimainkan tanpa GPS.
